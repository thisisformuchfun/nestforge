Edit the design, then rebuild the print.

The STEP files contain real boundary-representation solids. Each physical printed part also has a complete STL. The Python sources use CadQuery 2.7 and preserve millimetres with Z pointing up. These are digital prototypes; snap cycling, load capacity, seed flow and outdoor durability require physical trials.

Source files

originals.py, world.py, castles.py, sports.py, whimsy.py, future.py generate the six design families. common.py exports one connected solid per physical part and splits welded color regions. A colored region is part of the same print, not another loose component.

Use a specific model selector when rebuilding another castle from its individual print pack. Run a family in a fresh process. The source defaults write into the adjacent exports directory; NESTFORGE_EXPORTS overrides it. Read each module’s entry point for its supported model selectors. Do not run two writers on the same design directory.

The exporter validates STEP readback, publishes files atomically and caches validated bytes. After every writer stops, finalize_step_exports.py reports file integrity; --restore recovers only missing or empty files whose cache matches the exact design metadata. It never replaces a differing nonempty STEP.

What to adjust

Begin with the smallest mating latch. Beam thickness, hook engagement and receiver clearance are given in design.json and the family source. Change mating geometry together, regenerate, and recheck the assembly before packing. Scaling an STL also scales the snap clearance and the printed mesh openings, so it is not a substitute for editing those dimensions.

Surface courses, carved seams, ribs and sculptural details are geometry. Large visual textures therefore survive STL and STEP export. The website also adds subtle material shading; that shading does not claim additional printable detail.

Build and color conventions

Each 3MF is an unsliced native Bambu Studio project for an X1 Carbon with 0.4 mm nozzle. It contains arranged physical objects, each with welded material regions. Every plate uses at most four filament slots. A six-color build uses different slot loads between plates; follow each plate’s palette. Use compatible polymers in all slots.

The packer reserves the front-left exclusion, margins, part spacing and a rear prime-tower envelope on mixed-color plates. Round and irregular objects are checked using their full projected convex hull against the tower envelope expanded by 8 mm; empty bounding-box corners can therefore be used safely. Native Bambu Studio import, export and reopening verify material-region assignments and placement. Review the actual sliced tower, brims and supports before printing. No G-code or tested load rating is supplied. The website shows unsliced geometric planning ranges; confirm print times after slicing.

Reproducing native plate conversion

Set BAMBUSTUDIO_BIN to the official Bambu Studio executable and BAMBUSTUDIO_PROFILES to its resources/profiles/BBL directory. BAMBUSTUDIO_LIB is an optional command-scoped library path. The build used Studio 2.8.2.61. The converter never sends a print.

Assembly

Positive hooks retain the trays, bodies and service covers. The single upper hanger holds the completed rigid assembly; cord does not retain loose levels. Remove all supports and strings from latch windows and feed ports. Test the release action before filling. Read the individual guide for the refill opening and cleaning sequence.
