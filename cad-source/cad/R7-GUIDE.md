# Backyard camera feeders, R7

Ten different physical architectures replace the R6 hotel collection. The original 37 feeders remain available. Camera grips share published device envelopes; feeder bodies, seed systems, camera locations and mounting are independently designed.

All dimensions are millimetres, Z up. Generate a selected model from backyard_traditional.py, backyard_organic.py, backyard_gravity.py or backyard_structural.py. From the cad directory, for example: `python backyard_traditional.py orchard-hopper`. Each module takes one model ID as its positional argument. Set NESTFORGE_EXPORTS to a working output directory before importing common.py. Required Python libraries include CadQuery, trimesh, numpy, scipy, vtk, numba and Pillow. Read and retain the per-build metadata and assembly instructions.

The camera is purchased equipment, never printable geometry. Body contours and lens positions in preview images are illustrative; Birdfy's 90 mm visible body is a display placeholder within the published 230 mm envelope including antenna. Published external dimensions do not certify a physical fit. Side grip preload, snap fatigue, mounting strength, drainage, focus and sensor triggering all need a physical prototype. Wyze Battery Cam Pro requires its official close-up lens; accessory dimensions were not published in the source reviewed. Camera choice is specific to each build. Do not substitute a different model in a nominally similar bay.

R7 plates use Generic ASA, <=4 colors per complete feeder and <=4 per plate. The supplied 3MF files are native Bambu Studio projects with X1C plate placements and color assignments, not sliced G-code. Select your actual ASA profile and inspect supports and purge tower placement. Website times are geometric planning ranges; supports are excluded. Use Bambu Studio for actual time and material consumption.

STEP downloads contain printed solids. Full print packs contain individual STL parts and populated native 3MF plates. The website shows the actual arranged part geometry on 256 x 256 mm plates. Purchased cameras, mounting screws/straps/cord and the optional reused bottle are excluded from printed part counts. A printed part that has multiple colors remains one physical part.

Each build documents its mounting type and camera removal path. A wall/post design has no suspension cord. Hanging models use a cord only to support an already assembled rigid feeder. Seed bins and covers use their documented snaps; a cord does not hold them together. Remove electronics before washing. Use only the stated seed type and a shallow daily portion in open platforms.

The bottle model requires a measured compatible recycled bottle and support bead, not a universal soda-bottle thread. Its CAD and description state the nominal dimensions. Confirm neck fit and bottle clearance with the actual bottle before printing a full build.

The old R6 Vegas sources are retained as historical parametric work. They are not the active camera collection or compatible replacement parts for R7.
